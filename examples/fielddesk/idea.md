# Natural-language idea

Build a field-service dashboard for small operations teams.

Customers request repair jobs. Managers see a live board, technicians receive
assignments, urgency is calculated from the request, travel time comes from a
maps provider, and invoice drafts are prepared through a payment provider.

The developer should not need to stitch together a separate API framework,
ORM, auth library, background worker, UI framework, test runner, and service
SDK. Sovra should make the application boundaries explicit in one project.
