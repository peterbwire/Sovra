START BUILDING

Your first
Sovra program.

Install Git and Rust (1.74 or newer), then run these commands in your terminal. This builds the experimental CLI from source; no public binary installer is available yet.

After installation, download the example above as main.svr and run svr run main.svr from its directory.

Build from source Windows · macOS · Linux
git clone https://github.com/peterbwire/Sovra.git
cd Sovra
cargo install --path . --locked
svr run examples/hello-world/main.svr

Expected output: Hello, Sovra! If your shell cannot find svr, restart your terminal and check that Cargo's bin directory is on PATH.
